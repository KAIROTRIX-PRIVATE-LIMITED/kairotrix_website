## 12. MOTION PHILOSOPHY (LOCKED)

The website uses **different motion techniques per section** — not uniform animation everywhere.

| Section | Motion Technique | Purpose |
|---|---|---|
| Hero | Scroll-controlled cinematic video | Capture attention |
| Discovery | Smooth / refined transitions | Narrative continuity |
| Work | Interactive demonstrations | Demonstrate capability |
| How We Think/Build | 3D / parallax storytelling | Demonstrate thinking + interaction |
| Insights | Restrained — content-first | Establish expertise |
| Contact | Minimal, confidence-building | Convert |

### Motion Rules
- Scroll down → hero video progresses forward
- Scroll up → hero video plays backward
- Each section has its own motion language; hero video does NOT extend through entire page
- `prefers-reduced-motion` respected everywhere — parallax degrades to simple fades
- Every interactive element defines: Default / Hover / Focus / Active / Disabled / Loading states

## 13. VISUAL DESIGN SYSTEM (LOCKED TOKENS)

### Color System
| Token | Value |
|---|---|
| Brand Anchor (Kairo Purple) | `#9333EA` |
| Dark Background | `#08080C` |
| Light Background | `#FFFFFF` |
| Surface Dark | `#0F0F17` |

### Color Usage Discipline
- ~70-85% neutral / 10-20% brand / 5-10% accent (starting ratio, not rigid rule)
- Purple is not a background flood color — it appears in CTAs, active states, highlights, key accents

### Gradient System
| Gradient | Value | Use |
|---|---|---|
| `gradient-brand-core` | `#9333EA → #7C3AED` | Primary CTAs, key highlights |
| `gradient-signature` | `#9333EA → #6366F1 → #4338CA` | Hero, How We Think/Build, section dividers |
| `gradient-glow` | Radial `#9333EA` 25-40% opacity | Ambient lift behind hero/3D |
| `gradient-surface-dark` | `#0F0F17 → #08080C` | Dark mode surface depth |
| `gradient-surface-light` | `#FFFFFF → #FAFAFC` | Light mode hero/feature lift |
| `gradient-mesh` | Multi-point mesh (purple + indigo) | Hero backdrop, section transitions — sparing |

### Gradient Rules
1. Purpose over decoration — signal transformation, depth, or brand presence
2. One dominant gradient per viewport
3. Never on body text backgrounds
4. Accessibility: WCAG 2.2 AA — ≥4.5:1 normal text / ≥3:1 large text
5. Reduced-motion: animated gradients must have static fallback
6. Linear gradients default to 135° angle

### Typography Direction
**Modern + Premium + Technical** — precise and confident, not futuristic-AI-startup cliche.
Candidates: Manrope, Geist, Inter, IBM Plex Sans (finalized during visual prototype phase)
Scale: Display → H1 → H2 → H3 → Body Large → Body → Small → Caption (responsive tokens)
Weights: Regular / Medium / Semibold / Bold only

### Color Mode Strategy
- **Build all three: Dark, Light, Hybrid** as real page prototypes
- Decide after seeing real usage, not swatches
- Hybrid (light + dark + Kairo Purple transitions) is strongest candidate but unlocked until validated

### Visual Language
- Signature concept: **Transformation** — `Disconnected → Understood → Structured → Connected → Intelligent → Evolving`
- **Do:** strong grid, generous whitespace, high typographic hierarchy, controlled density, geometric forms, subtle depth, purposeful motion, original visuals, technical diagrams
- **Avoid:** generic robot/AI-brain imagery, excessive glow, cyberpunk aesthetics, floating 3D objects, stock photography
