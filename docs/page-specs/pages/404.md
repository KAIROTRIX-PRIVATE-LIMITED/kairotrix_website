# PAGE SPEC: 404 ERROR PAGE

> **Status:** Spec ready — build in Phase 7 (Polish)
> **Route:** `/not-found` (Next.js 15 — `not-found.tsx`)
> **Motion Level:** ⭐⭐⭐ Subtle — a moment of personality

---

## PURPOSE

The 404 page is an opportunity, not a failure. When someone lands here, they're either:
- Lost from a broken/old link
- Exploring the site
- Testing the experience

The 404 should:
1. **Clearly communicate** they've reached a non-existent page
2. **Feel like KAIROTRIX** — premium, not generic "Page Not Found"
3. **Help them get where they want to go**
4. **Be a moment of brand personality** — not just an error

---

## CONCEPT OPTIONS

### Option A — Minimal & Typographic
```
┌─────────────────────────────────────────────────────┐
│                                                     │
│                   404                               │
│                                                     │
│         This page doesn't exist.                   │
│         But KAIROTRIX does.                        │
│                                                     │
│         [ Back to Home ]  [ Explore Work ]         │
│                                                     │
│         Or describe what you were looking for:     │
│         [ Talk to KAIROTRIX AI ]                  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### Option B — 3D / Interactive Error
- Small Three.js scene — a geometric form floating in space
- "404" appears as a large, glitchy or dissolving typographic element
- Consistent with the technical/premium brand
- More ambitious — may not be worth the effort for V1

### Option C — Brand-Driven
- Large "404" in Kairo Purple
- Short, confident message
- Quick navigation back

**Recommended: Option A** for V1 — maximum impact with minimal build effort. Can upgrade to B later.

---

## CONTENT

### Headline
- *"404"* — large, typographic
- Or: *"Nothing here."*

### Sub-copy
- Short and human: *"This page doesn't exist — but KAIROTRIX does."*
- Or: *"You've gone somewhere we haven't built yet."*

### Navigation Options
```
[ Return Home → ]         ← primary
[ Explore Solutions → ]   ← secondary
[ View Our Work → ]       ← secondary
[ Talk to KAIROTRIX AI ]  ← opens AI assistant
```

---

## MOTION DETAILS

| Element | Motion |
|---|---|
| "404" text | Fades in with slight scale 0.9 → 1 |
| Sub-copy | Fades in 300ms after headline |
| Nav links | Stagger in after copy |
| Optional: | Floating geometric shape (slow rotation) |

---

## DESIGN NOTES

- Background: dark (`bg-bg-dark`) — consistent with brand
- "404" numerals: very large display size, `text-brand-500` or `text-neutral-200`
- Keep it confident and brief — no lengthy explanations
- Total page height: centered vertically (no scroll needed)

---

## DEPENDENCIES

- Framer Motion (entry animations)
- AI Assistant (for the "Talk to KAIROTRIX AI" option)
- Next.js `not-found.tsx` convention
